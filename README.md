# 项目过程管控平台

## 样式规范

```
  查询、重置位置摆放:查询 重置
  功能按钮：进行归类，比如版本创建、版本修改之类的按钮，使用按钮组，进行统一归类，危险操作类功能
  主操作按钮：使用默认主题颜色 提交、保存、确认等操作按钮
  次要操作按钮：编辑、预览等操作按钮使用淡绿
  危险操作按钮：删除、取消等使用红色
  警告按钮：更新或者警告等操作按钮使用黄色
  信息按钮：查看详情或者帮助、更多信息使用蓝色
  链接按钮：忘记密码、查看协议等使用蓝色或者与文本颜色一致
  辅助按钮：返回、关闭等按钮使用灰色

```

## 环境

```
  使用 nodejs 14 版本进行安装
  npm install 安装依赖
  npm run dev 启动环境
```
