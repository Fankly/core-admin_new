# 省级统筹目标值 mock

页面：`/targetBudget/provinceTarget/index`。由根目录 `mock/index.ts` 在开发环境加载，页面和 API 继续使用原有请求。

- `data.ts`：多年度版本、项目类型、单位、项目清单、版本独立状态及金额计算。
- `index.ts`：本页角色、按钮权限、字典、版本增删改查、动态表头、维护和汇总、版本比对、项目确认和审批。
- `files.ts`：Excel 模板、导入导出及附件上传、查看、下载、删除。

当前年度有 24 个版本，覆盖草稿、已提交、审核通过、审核驳回、已过期；每个版本有 12 条项目明细，覆盖新增、调整、取消。下一年度无预置版本，可验证空列表和创建。新增、保存、删除及提交会在当前浏览器会话中回显，刷新页面后重置。

总控值按项目大类校验平衡，待分解金额不得小于零。项目明细保存后，维护表和调整汇总根据明细重新计算。不同版本的数据互不影响。

Excel 导入支持本页下载的 `.xlsx` 文件：目标总控值使用专用模板；项目明细可修改导出文件中的“当年预算（调整后）”“调整说明”“是否预安排”，也可导入待确认项目导出文件。所有行校验通过后才写入。附件保存上传的原始内容，预置附件为可打开的 Excel 文件。

公共权限接口按当前页面路由或模拟业务码收窄，兼容 `routeToMeta` / `menuMsg` 缓存的实际业务码；包含版本管理、目标值管理、流程履历及其全部子按钮，同时覆盖 `getButtonList` 和 `getButtonListNew`。批量字典接口因参数位于 POST body，仅在本页路由下拦截，其他页面保持原有请求；`NDCX` 单字典复用现有公共 mock，`getWjhNum` 复用 `goalValueVersion`。为方便联调创建和比对，本部门未激活版本数量固定返回数字 `0`，审批使用本地模拟回调。
