# 预算执行分析配置：临时 CRUD 测试副本

来源：`../budgetStatisticsConfig.vue`。页面、专用组件、校验和回归用例全部放在本目录，未修改正式页面和共享业务组件。

## 访问

- 菜单 URL / 组件路径：`/statistics/budgetExecutionAnalysis/budgetStatisticsConfigTest/budgetStatisticsConfig`
- 测试环境菜单绑定上述路径，并为测试角色配置 `ADD`、`EDIT`、`DELETE` 按钮权限；沿用现有 `userDialog` 角色和权限链路。
- 已有系统动态路由会按路径匹配本目录下的 Vue 文件，无需修改全局路由。通过地址直接访问仍需遵循系统的登录、菜单与权限流程。
- 本地独立预览：启动 `npm run dev` 后，访问 `http://localhost:8001/src/views/statistics/budgetExecutionAnalysis/budgetStatisticsConfigTest/tests/preview.html`。预览调用项目现有内存 Mock，任何未匹配的请求立即报错，不访问真实后端；刷新重置数据。
- **业务页面仍调用原 `budgetStatisticsConfig` 接口，共用所连接环境的数据。本目录隔离的是代码，不是数据库；正式验收请连接测试环境。**

## 本次规则

| 范围 | 约束 |
| --- | --- |
| 页面入口 | 主工具栏仅新增、修改、删除，保留年度、展示维度、树和列表；移除复制、指标关联、帮助。弹窗内保留完成 CRUD 必需的明细操作、保存和取消。 |
| 名称 | 去除首尾空白后必填，最多 31 个字符；同年度、同维度、同父节点下不允许重名，修改时排除自身。 |
| 序号 | 1 ～ 99999999 的整数；负数、小数、科学计数法、非数字不会被悄悄转换为另一个合法数。序号不要求唯一。历史数据为 0 的配置需在修改时改为有效序号。 |
| 其他文本 | 前台显示序号最多 31 字符；部门、预算来源、承诺项、备注各 120；统计承诺项/项目类型编码串 2000。提交前去首尾空白。 |
| 父子节点 | 末级节点不可新增子节点；有子节点时不能改为末级；父级停用时不能新增启用的子节点；有启用的子节点时不能停用父节点。编辑保留接口返回的原父节点。 |
| 数据明细 | 项目类型统计至少选择一个项目类型，或添加一条项目类型绑定；绑定仅能选择有效末级项目类型，相同项目类型不可重复绑定；包类型可空，表示全部。承诺项统计必须填写非空承诺项。 |
| 明细汇总 | 至少一个目标，禁止重复目标、自身、循环引用（包括通过父子关系形成的循环）、失效目标以及具有包含关系的目标。 |
| 分析节点 | 分析报告节点类型为 `1` 时普通分析节点必填；其他类型提交空值。 |
| 删除 | 支持多选；先停用，存在未一同删除的子节点或其他汇总引用时阻止删除。确认后重新读取状态和引用，取消不提交。 |
| 交互与失败 | 保存、删除防重入；失败保留输入并恢复操作；初始化失败禁止保存；切换年度/维度清空选择，过期响应不覆盖当前数据；表单打开时锁定页面上下文。 |
| 编辑明细 | 先在表单草稿中增删，保存时一次提交完整明细；取消不调用任何明细删除接口。切换统计模式清理不适用的字段和明细，不再重新拉取旧绑定。 |
| 同时编辑 | 保存前重新读取当前记录及明细，发现与打开时不同则阻止覆盖，提示重新打开。 |

## 回归

仓库根目录运行：

```sh
node --test src/views/statistics/budgetExecutionAnalysis/budgetStatisticsConfigTest/tests/crud.test.cjs
npx eslint src/views/statistics/budgetExecutionAnalysis/budgetStatisticsConfigTest --ext .ts,.vue
```

用例执行真实 Vue setup 和 watcher，仅替换网络与 UI 边界；覆盖字段边界、父子/汇总规则、ID 类型、取消明细编辑、重复提交、加载与提交失败、并发编辑、维度切换和 SFC 编译。

浏览器回归脚本：`tests/browser-smoke.js`。在全新 `tests/preview.html` 页面通过 `agent-browser eval --stdin` 执行，覆盖空末级节点拦截、明细保存回显、取消移除明细、修改和取消/确认删除。

本次验证结果：18 项自动化回归全部通过；ESLint、Vue SFC 脚本/模板编译及 `rules.ts` 独立严格类型检查通过。浏览器 Mock 环境已通过普通配置增改删、启用状态删除拦截、明细绑定保存回显与取消撤销，以及汇总目标保存回显。全项目 `vue-tsc --noEmit` 在 Node 默认约 4 GB 堆上限退出，未获得全项目类型检查结论。

## 联调验收与删除

前端和当前 Mock 的保存契约是：`saveConfig` 在同一事务中保存主记录，并**全量替换** `dataDetails`、`sumDetails`（空数组表示清空）。测试环境需要确认后端遵守此契约；如果后端只追加明细，需配套修改保存接口，不能用提前删除明细来代替，否则无法保证取消和失败时数据一致。

前端的重新读取可以拦截已观察到的修改，但不能代替服务端事务、版本校验、唯一约束以及权限校验。多用户在最后一次校验后的并发写入，仍需服务端保证。当前仓库未包含这些后端实现，也未对真实测试环境进行联调。

后期移除测试菜单并删除整个 `budgetStatisticsConfigTest` 文件夹即可；无需回退共享组件、全局路由或 API 文件。移除目录不会删除已经写入数据库的测试数据。
