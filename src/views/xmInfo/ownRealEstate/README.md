# 自有房产菜单配置

本页面由后端菜单接口动态注册，前端无需添加静态路由。

- 父菜单：项目信息
- 菜单名称：自有房产
- 菜单路由：`/xmInfo/ownRealEstate/index`
- 组件路径：`src/views/xmInfo/ownRealEstate/index.vue`
- 页面模式：菜单页面
- 角色配置：必须配置 `outsideMenu`，页面通过 `UserRoleSelector` 获取单位、部门、角色和按钮权限上下文
- 按钮编码：`ADD`、`EDIT`、`DELETE`、`IMPORT`、`EXPORT`；页面按返回编码严格显示操作，未配置按钮的角色保持只读

接口未提供导入模板下载地址，因此导入弹窗只开放文件上传，不展示无法工作的模板按钮。删除接口还要求年度、查询编码、审核信息和 UUID；页面优先读取选中记录，其次读取同名路由参数，没有值时显式传空字符串，后端返回的具体失败原因会直接展示。
