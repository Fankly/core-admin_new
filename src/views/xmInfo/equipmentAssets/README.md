# 设备资产管理菜单发布

本项目菜单由后端 `/sys/menu/nav` 按角色下发，前端路由会按菜单 URL 精确匹配 `src/views` 下的 Vue 文件。请通过系统管理的菜单管理功能发布以下配置，不要在 `base.ts` 中添加绕过权限的静态菜单。

## 菜单

| 配置项 | 值 |
| --- | --- |
| 上级菜单 | 项目信息 |
| 名称 | 设备资产管理 |
| 路由 | `/xmInfo/equipmentAssets` |
| 类型 | 菜单 |
| 打开方式 | 内部打开 |
| 是否显示 | 是 |
| 是否主页 | 否 |
| 是否内嵌 | 否 |

## 角色权限

页面使用 `src/components/UserRoleSelector` 根据菜单的 `outsideMenu` 获取当前用户可用角色。用户只有一个角色时直接进入；存在多个角色时先完成角色选择；没有可用角色时返回首页。

新增、编辑、删除等操作按钮不配置独立按钮权限，不需要在菜单下新增 `ADD`、`EDIT`、`DELETE` 按钮节点。请将“设备资产管理”菜单分配给需要维护设备资产的角色，并正确配置菜单 `outsideMenu`。
