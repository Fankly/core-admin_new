# 架构与 UI 重构验收

验收日期：2026-10-22。范围是当前 `core-admin_new` 骨架仓库：登录、工作台、外壳、导航、标签页、iframe 适配、公共表格和请求能力。邻近完整仓库的业务模块没有迁入，也没有以虚构页面或数据代替业务实现。

## 完成内容

- 保持 `views/` 路径适配和服务端菜单契约，业务实现归入 `features/`；可用导航和搜索统一消费 `menu.navigationEntries`，缺少视图的入口与空分组不展示。
- 工作台拆为页面、业务目录和平台状态组件；提供名称搜索、分组筛选、分批展示、继续工作和账号信息，状态接口仅在抽屉打开时请求。
- 延续青绿品牌 `#00706b`，统一页头、空状态、链接与语义 token；外壳样式按职责拆分，侧栏调整逻辑独立为 composable。
- 仅提供桌面布局，移除小屏导航抽屉、入口、状态、适配样式和移动测试项目；公共表格搜索布局仅保留桌面断点。
- 导航固定使用手风琴，打开同级目录时收起前一个分支；父子菜单从父级文字起点递进，保留原有图标显示方式。
- 修复混合导航顶部选择事件，模块切换同步侧栏，刷新后按菜单树恢复页面所属模块；侧栏收起样式仅作用于垂直导航，顶部溢出菜单随可用宽度重算。
- 界面设置先展示布局及其说明，再展示外观和标签页，底部固定恢复与复制操作；设置实时生效并持久化。
- 完善全局搜索快捷键、焦点、方向键、Enter 和 Escape；修复内部入口 href、工作区跳转焦点和标签页滚动边界。
- 登录重新开始时清理菜单路由、标签页和会话；菜单初始化忽略重置前的响应，工作区失败重试重新请求菜单。
- iframe URL 保留既有查询参数和 hash，嵌入状态按实例清理，配置失败可恢复。
- VXE / Excel 导出依赖在进入工作区时加载，图表组件异步加载，注册完成后渲染外壳；移除人为启动和路由等待。

在仓库根目录执行：

| 命令                                | 结果                    | 验证范围                                                |

| `pnpm lint`                         | 通过                    | 应用 TypeScript / Vue 规则，无新增 suppression 基线     |
| `pnpm typecheck`                    | 通过                    | Vue / TypeScript 类型检查                               |
| `pnpm --filter budget-process test` | 75 / 75 通过，12 个文件 | 请求、组件、store、路由、导航搜索、菜单归属、iframe URL |
| `pnpm build`                        | 通过                    | production 模式构建                                     |
| `pnpm --filter budget-process e2e`  | 9 / 9 通过              | 桌面交互、导航层级、手风琴、混合导航和界面设置          |

Playwright 使用本机 Chrome，在 1440×900 视口运行，导航布局场景额外检查 900px 宽度仍保留桌面侧栏与调整入口。受控响应仅覆盖 `/api/` 和测试 iframe，Vite 源码模块正常加载。场景包括：

1. 可用入口过滤、搜索无结果与清除、模块点击、iframe 展示和主页标签返回。
2. 全局搜索输入聚焦、方向键选项、快捷键重开、Enter 跳转与 Escape 关闭。
3. 平台状态首屏不请求、打开抽屉后请求并显示、Escape 关闭。
4. 顶部 / 混合导航、侧栏键盘调整与复位、窄窗口继续显示桌面导航。
5. 权限拒绝后重新验证，以及菜单初始化失败后重新加载并恢复工作台。
6. 七层菜单的父子缩进，保留图标有无差异，侧栏收起后图标居中。
7. 同级分支互斥展开、父级保持展开、再次点击收起，旧的非手风琴设置不再影响行为。
8. 混合导航模块切换、溢出菜单选择、刷新恢复、侧栏收起后顶部菜单仍可见。
9. 设置选中状态、适用选项、外观持久化、关闭标签页后禁用样式选择与恢复默认。

工作台场景额外检查标题处于视口、无横向文档滚动、无页面异常和未注册组件警告。这些检查验证前端行为；它们不证明外部业务系统的接口、数据和写操作正确。

## 视觉走查

通过本地开发服务和可读取的真实菜单走查桌面工作台与手风琴导航；自动化覆盖 1440×900 桌面视口。工作台标题完整、长分组可以换行、筛选控件可用，文档无横向滚动。工作台使用内容容器宽度决定目录与辅助信息的布局，窄桌面优先保证目录的阅读空间。

## 构建体积记录

本轮记录的主生产 JS chunk 从约 2.5 MB 调整为约 642 KiB（657,360 字节，未压缩）。登录阶段不再加载整个 VXE / Excel 导出栈；工作区插件作为独立 chunk 后续加载。

该数值只描述主 chunk。入口还预加载 Element Plus 等独立 vendor chunk，工作区依赖总量没有随拆包消失，因此不能把主 chunk 的降幅当作完整首屏传输量、压缩后体积或端到端加载时长的改进。

## 后续业务接入

新增页面仍须保留与菜单 URL 一致的 `views/` 适配文件，实现放在 `features/<domain>/`，接口放在 `api/<domain>/` 并声明业务类型。业务迁移时继续验证角色差异、外部 iframe / fullscreen 组合、真实表格数据和业务写操作。当前仓库缺失的业务域需要原始页面与接口事实，不能仅由外壳重构推断。
