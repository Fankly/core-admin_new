## 认证边界

生产登录由外部系统提供，目前尚无外部入口、token 获取或身份交接协议可供对接。本轮完成的是移除生产内置凭据和自动联调登录；生产登录页显示“请从企业统一入口访问”，不发送登录或权限请求、不提供无效的重新登录按钮。

这不代表 SSO 已接入。生产接入仍需确认外部系统如何向后端或前端传递登录身份；现有后端鉴权契约保持不变。`VITE_APP_LOGIN_*` 只用于开发联调，禁止配置真实生产口令。
